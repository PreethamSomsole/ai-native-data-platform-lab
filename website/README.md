# Project showcase website

The showcase is a single self-contained HTML file: `index.html`. It includes all page content, styling, and embedded SVG interface previews, with no build step or local asset dependencies. Open it directly in a browser or serve the repository root and visit `/website/`.

The interface previews are illustrative production concepts, not captures of a deployed enterprise UI. The behaviors and definitions are grounded in the repository reference implementation; authentication, enterprise control-plane views, and production integrations are future work.
